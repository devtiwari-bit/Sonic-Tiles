# Sonic Tiles

Tap the falling tiles in time with the music. A free rhythm game by Ved Games Production.

## Features
- Opening screen, menu, and four levels: Easy, Medium, Fast, God
- Endless play: new tile patterns, and the speed rises every 5,000 points
- Achievements, saved in the browser
- Three themes: Neon, Jungle, Temple
- Installable as an app (Download App button)

## Files
- `index.html`: the whole game in one file
- `site.webmanifest`: install settings and icons
- `sw.js`: offline support
- `logo.svg`, `favicon.svg`, PNG icons: branding
- `robots.txt`, `sitemap.xml`: search engine files

## Before publishing
1. Replace `YOUR-DOMAIN.com` in `index.html`, `robots.txt`, and `sitemap.xml`.
2. Paste your Google Search Console code into the `google-site-verification` meta tag.
3. Upload all files to the same folder on your web host (served over HTTPS).
